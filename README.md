# Kindred

A place-based community app for neighbors to request help, offer skills, share surplus, and gather in real life.

Glassmorphic mobile UI. Forest sage is the default look. Ink (black and white) and Light live under **You → Settings**.

## What you can do

- Stream of requests, offers, events, discussions, resources, and projects
- Skill matching against your profile
- Neighborhood map of people, posts, and groups
- Groups, inbox, and profiles
- Compose a post and RSVP or offer help

Demo data is set in Los Angeles. Nothing leaves the browser — posts, messages, and profile live in local storage.

## Run it

```bash
npm install
npm run dev
```

Then open the app in your browser.

## Stack

TanStack Start, React, Tailwind v4, Zustand.
